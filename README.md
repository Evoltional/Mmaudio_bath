# MMAudio 批量视频处理工具

一个基于 ComfyUI 工作流的桌面 GUI 工具，用于批量对视频进行 MMAudio 音频处理。自动完成视频分割、提交 ComfyUI 生成、合并输出等全流程，并支持断点续传、失败跳过与手动合成。


## ✨ 功能特性

- **智能视频分割**  
  将长视频按 5 秒切割成片段，超过 9 秒的片段自动对半重编码，避免 ComfyUI 处理时显存/时长溢出。

- **自动合并短片段**  
  对于时长不足 5 秒的片段，尝试与相邻片段合并，合并后总时长不超过 9 秒，保证处理效率。

- **全自动提交 ComfyUI**  
  逐个片段调用 API 提交工作流，等待生成输出，并自动收集 `MMaudio_seg_xxx-*.mp4` 结果文件。

- **失败容错与断点续传**  
  单个片段处理失败时自动跳过并备份原片段，进度实时保存至 `progress.json`，重启后可从中断处继续。

- **手动合成模式**  
  处理中途停止后，可通过右侧“未合成视频”列表手动将已生成的片段合成为最终视频。

- **GUI 实时反馈**  
  图形界面实时显示日志、进度条、视频状态，所有配置均可通过界面修改并自动保存。

- **目录自动清理**  
  合成后可自动清空 ComfyUI 的 `output`、`temp` 目录及临时片段，保持环境整洁。

## 🛠️ 环境依赖

| 依赖项       | 版本/说明                    |
|--------------|----------------------------|
| Python       | 3.7+（需内置 `tkinter`）     |
| ComfyUI      | 需启动并开启 API 访问        |
| FFmpeg       | 包含 `ffmpeg` 和 `ffprobe`  |
| Python 库    | `requests`                 |

**注意**：  
- 需将本项目自带工作流导入程序（放入同一文件夹即可），comfyui打开该工作流并保持启动。  
- 确保 ComfyUI 的 `--api` 启动参数已启用（整合包通常已启动，无需操作）。  
- FFmpeg 建议添加到系统 PATH，否则需在界面中指定完整路径。

## 📦 安装与快速开始

### 1. 克隆或下载脚本
将本项目文件放置到任意目录，例如 `D:\MMaudio_batch\`。主要文件：
- `mmaudio_batch.py` — 主程序
- `config.json` — 自动生成的配置文件（首次运行后创建）
- `progress.json` — 进度保存文件

### 2. 打包项目

```bash
pyinstaller --onefile --windowed --name Mmaudio_bath Mmaudio_bath.py
```
